# GitHub Contribution Snake Game in Python 🐍

---

##  Game Modes / Scripts

* **`snake.py` (Standard Mode)**  
  Plays on a randomized contribution-like board with classic gameplay mechanics and procedural block respawns.

* **`snakegithub.py` (Live Profile Mode)**  
  Prompts for a GitHub username on launch, downloads their real commit history for the past year, and turns their actual contribution board into the playable level.
